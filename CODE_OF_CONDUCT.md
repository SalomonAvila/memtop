# Code of Conduct

memtop follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions focused on
the project. Harassment, insults and personal attacks are not tolerated in issues, pull
requests or any other project space.

The maintainer may edit or remove comments, close discussions, and block anyone who does not
follow this code. To report a problem privately, use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature or contact the maintainer through their GitHub profile.
